# User feedback on the Phase 1 demo (2026-10-05)

The user is sending reference screenshots, mostly from Lagos Life. **Don't start the redesign items until those arrive.** These items are the user's direction, not final specs.

## Language
1. **Use moderate Pidgin, not full Pidgin everywhere.** The current amount reads as forced and weird.
   - **Landing page:** plain English.
   - **In game:** mostly clear English, with Pidgin only where it fits naturally, in street moments such as agberos, robberies and market banter. It should sound like a real Benin person, not a parody.
2. **Nepo babies say "Dad"/"Daddy", not "Papa".** They're school-trained and speak polished English. LAPO babies can keep a street voice.

## Look and feel
3. **Redesign the in-game UI.** The user doesn't like the current colours or theme ("looking weird"). Wait for the reference screenshots.
4. **Landing page.** Use the `design-taste-frontend` and `emil-design-eng` skills.
   - It should be a polished page that complements the game, separate from it. It shouldn't look like the game has already started.
   - **Don't show any LAPO/Nepo percentages or starting amounts on it.**
5. **Redesign the login and sign-up pages too.** References are coming.
6. **Add more detail to the map.** The user likes the map but finds many parts not detailed enough yet.

## Character creator
7. **360° turn:** players can drag or rotate the character to see it from the front, side and back.
8. **Face shapes:** the user likes the character design but wants more than a round face. Add selectable face shapes (round, oval, square/strong jaw, long, heart, and so on).
9. **Outfits:**
   - Add more options, each with a clear label, for example "Bini Traditional Wear".
   - **Turn outfits into presets.** Picking "Yahoo Boy" applies a whole look: outfit, shades, cap, wristwatch, chain and so on. Do the same for every look (corporate, student, market woman, and so on). Each item can still be tweaked after the preset is applied.
   - **Yahoo look:** drop the pink. Use another colour that still has the Yahoo vibe.
10. **The creator is for looks only.** Players choose a career track later, in the game.

## Admin control
11. **The admin dashboard must control everything in the game.** That includes:
    - Sleep and activity times (the user wants sleep short, no long waits).
    - Starting cash and bank for each origin.
    - Origin probabilities.
    - Allowances, prices, robbery chances, and so on.
12. **Origin roll.** The user sets a fixed percentage in admin and can change it later.
    - **For testing:** the user's first account (already created) is LAPO. **The next account they create must be Nepo.** This needs an admin/dev override, such as "force the next new account's origin" or setting an origin per account.

## Open questions from HANDOFF.md
These were asked; the answers above cover them in part.
- **Q1:** jail and hospital time. The user wants everything adjustable in admin; a separate crime rate is assumed fine.
- **Q2:** landing theme. A redesign is coming, so it's superseded.
