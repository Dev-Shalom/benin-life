# Benin City OSM building data

`../../src/art/city3d/data/benin-core-buildings.json` contains a compact selection of closed building-way footprints derived from OpenStreetMap for the downtown Benin City window described in `../MAP_GEO.md`.

The game displays a persistent, clickable OpenStreetMap attribution on both the 3D city and Lite map. The source extract was retrieved from the OpenStreetMap API on 2026-10-08. The conversion script is `scripts/import-osm-buildings.mjs`.
